头像放在这个文件夹里，按「两位座号」命名即可。
======================================================================

支持这四种扩展名，程序会依次尝试，命中哪个用哪个：

    01.png
    01.jpg
    01.jpeg
    01.webp

  02.png   ← 座号 2
  03.jpg   ← 座号 3
  ...
  09.webp  ← 座号 9（01~09 一定要补零！）
  10.png   ← 座号 10（之后的照写）

说明
----
1. 文件名里的数字就是 STUDENTS 里的 seat，不是学生排第几个。
2. 四种扩展名都没有时，自动用「姓名首字 + 按座号稳定生成的圆形底色」
   当默认头像，不会出现裂图。
3. 想让某个学生用别的文件，可以在 STUDENTS 里直接写 avatar 字段：

       { seat: 3, name: "王五", avatar: "photos/wangwu.png" }

   路径相对于 index.html；同样支持加载失败自动回退默认头像。
4. 建议用正方形图片（比如 512×512），程序会圆形裁切并居中显示。
5. 这个文件本身可以删，不影响运行，只是方便你记住命名规则。
